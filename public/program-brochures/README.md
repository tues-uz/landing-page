# Program brochures (PDF)

Each program detail page offers three downloads (all use the slug from `src/components/Programs.tsx`):

| File | Purpose |
|------|---------|
| `{slug}.pdf` | Program brochure — overview & highlights |
| `{slug}-admissions.pdf` | Admissions — apply & requirements |
| `{slug}-curriculum.pdf` | Curriculum — courses & structure |

- **`default.pdf`** is the template; placeholder copies were generated from it — replace with real PDFs (keep filenames).
- When adding a new program, add all three `{slug}*.pdf` files here.
